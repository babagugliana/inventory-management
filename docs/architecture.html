Architecture overview

Factory Inventory Management System

A two-tier demo app: a Vue 3 single-page app talks over HTTP/JSON to a FastAPI service. The API serves read-only mock data that it loads from JSON files into memory when it starts. There is no database, no authentication and no write path on the server.

Data flow: changing a filter

The global filter bar drives most screens. This is the full round trip when a user changes one filter.

  1. User picks a value in FilterBar

    Time Period, Warehouse, Category or Order Status. FilterBar sits in App.vue, so it is visible on every page.

  2. Shared refs update in useFilters

    The four refs are declared at module scope, so every component shares one copy of the filter state (a singleton).

  3. The active view's watch() fires

    It calls getCurrentFilters(), which maps the period to a month param such as 2025-03 or Q1-2025.

  4. api.js sends the request

    It builds URLSearchParams, omits any value of "all", and makes an axios GET to http://localhost:8001/api/….

  5. FastAPI filters in memory

    apply_filters() does exact matches on warehouse, category and status (case-insensitive for category and status). Then filter_by_month() does a substring match on order_date.

  6. Pydantic validates and serializes

    Endpoints that declare a response_model are validated against it. Summary, spending and report endpoints return plain dicts.

  7. The view re-renders

    The response goes into refs such as allOrders and inventoryItems. Computed properties derive the KPIs, chart series and table rows.

Things worth knowing

I found these by reading the code. They aren't documented anywhere else.

GapClient calls endpoints the server doesn't have

api.js defines /api/tasks (GET, POST, PATCH, DELETE) and /api/purchase-orders, and App.vue uses the tasks calls for TasksModal. main.py implements neither, so these requests return 404.

OrphanBacklog.vue has no route

The view exists and fetches backlog data, but main.js never registers it. The backlog is surfaced only through the Dashboard and its detail modals.

QuirkDashboard backlog count ignores filters

total_backlog_items in /dashboard/summary is always len(backlog_items), whatever filters are active.

QuirkTime handling is fixed to 2025

QUARTER_MAP and the report quarter logic only know Q1–Q4 2025. Month filtering is a substring match on the date string.

DesignThe server holds no state between restarts

Data is loaded once at import, and nothing ever writes it back. Edits to the JSON files take effect only after the API restarts. Change the Pydantic models along with any change to the JSON shape.

DesignConfiguration is hard-coded

The API base URL (localhost:8001) is hard-coded in api.js and Reports.vue, and CORS allows every origin. That is fine for a local demo and would need changing before any deployment.
